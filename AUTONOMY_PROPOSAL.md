# THREE PROPOSALS — SO A DAY OF ABSENCE COSTS A DAY, NOT AN EXCHANGE

**PROPOSED, NOT INSTALLED.** Seat 3 rules; nothing here is in force until then.

**THE RESIDUAL THESE ANSWER.** The deploy mechanism removed the *restart* cost. What remains
is that **the loop terminates on Seat 3**: every finding waits for a ruling, so a day of
absence yields one exchange of progress. The gap is not permission in general — it is that
**"apparatus vs subject" says what is Seat 3's to DECIDE and never said what is mine to ACT
on unsupervised.** Those are different questions and only the first was ever answered.

# 1 · WHAT I MAY TAKE WITHOUT A RULING

## THE DISCRIMINATOR, IN ONE LINE
> **Can this be undone in one recorded step, and does it change the meaning of any number
> already on the board?**
> **Undo is one step AND no existing number changes meaning → TAKE.** Otherwise **QUEUE.**

Both halves are necessary and neither is sufficient. A one-step undo on a change that
re-defines a live metric still corrupts every reading taken before it; a change that touches
no metric but cannot be undone is still irreversible. **The conjunction is the criterion.**

## TAKE — no ruling needed
| class | why it is safe | the receipt it must leave |
|---|---|---|
| **Reads** — any depth, any subsystem | change nothing; cost is time | the reading, with population and as-of |
| **Instruments that only observe** | produce a number, move no state | **R4 both ways before the first citation** |
| **Builds behind their own falsifier** | the falsifier bounds what "wrong" means before it can be rationalised | prereg written FIRST · gate mutation-tested · **blast radius measured, not assumed** |
| **Reversible operational changes** — mode, thresholds re-derived onto state, deploy config | one-step undo, no evidence touched | the undo, written down, in the commit |
| **Corrections and retractions of my own claims** | leaving a wrong claim standing is the larger harm | the original struck, not deleted |
| **Retiring superseded documents** | a stale doc reads as current | a note saying **what replaced it** |

## QUEUE — waits for Seat 3
| class | the worked case |
|---|---|
| **Irreversible anything** — deletion without a record, schema migration | the ledger genus |
| **Anything touching the ground's record** — `action_traces`, `levelup_frames`, scorecards | **D-4**, which Seat 3 closed by ruling the table off limits |
| **Anything that changes what a reading MEANS** — re-tuning a constant a live claim rests on, redefining a metric, rewriting a test assertion to match new behaviour | the standing red `test_zero_score_games_deleted` |
| **Anything that ARMS a latent defect** | **D-1 before the frontier writer** — the repair is what arms it |
| **Verdicts and content** | Seat 2 may author *conventions*; a verdict and an atom both make claims about the world |
| **Anything with a visible external cost** | a scorecard run; restarting the roster |

**THE ASYMMETRY IS DELIBERATE.** Taking a read that should have been queued costs time.
Taking a change that should have been queued can cost evidence that cannot be regenerated.
**When the criterion is genuinely ambiguous, the item is queued** — and *that ambiguity is
itself reportable*, because a criterion that is ambiguous often is a criterion stated wrong.

# 2 · THE STOPPING CONDITION

**A property, not a feeling.** I stop and wait when **any** of these holds — each is checkable
without judgement:

**S1 · THE NEXT ACTION REQUIRES A RULING** by the criterion in §1. *(Seat 3's.)*

**S2 · THE TOP QUEUE ITEM DEPENDS ON A READING THAT HAS NOT RETURNED.** *(Seat 3's.)* The
Ladder's own rule: **a step whose input never arrived cannot be diagnosed, only its
predecessor can.** Working the second item instead is legitimate; working *below* the missing
reading is not.

**S3 · THE SAME DEFECT CLASS HAS BEEN FOUND THREE TIMES WITH NO RULE INSTALLED.** *(Seat 3's,
and it is SITE-SCOPED KNOWLEDGE applied to me.)* Three instances means **the rule is owed**;
finding instance four is motion. *This week would have tripped it twice — on
built-plumbed-never-called, and on wall-clock thresholds.*

**S4 · MY LAST THREE ACTIONS MOVED NO NUMBER ON THE BOARD.** *(Mine, and it is the one I most
need.)* I diagnosed myself working above the break — 42 commits, 0 wins — and **the declared
stake is standing, which biases me toward producing a finding over reporting nothing.** S4 is
the mechanical check on that bias: three consecutive actions that move no measured quantity
means I am generating residual rather than answering it, and I stop and say so.

**S5 · A CORRECTION I ISSUED IS CONTRADICTED BY A LATER READING.** Stop and re-derive rather
than layering a second correction on the first. *(Today: the scorecard framing, retracted
whole rather than amended.)*

**WHAT STOPPING LOOKS LIKE:** the board written up with the blocking item named, the swarm
left running, and **no half-finished change in the tree** — because the working tree is
production and a half-finished change deploys within 60 seconds.

# 3 · HOW THE QUEUE RE-RANKS ITSELF

**The ranking is a function, not a list**, and it re-runs **at every beat and after every
completed item** — so it cannot be stale by hour three. Lexicographic, in this order:

**R1 · EXPIRY — what stops being answerable if I wait.**
Evidence that will be gone: a run that ends, a log that rotates, a latent whose threshold is
approaching, a live regime about to change. *D-5's boxes grow; D-4 was 23 days out.* **An
expiring item outranks a more important permanent one, because the permanent one will still
be there.**

**R2 · BLOCKING COUNT — how many queued items have this as a predecessor.**
Computed from the dependency chain, not from importance. *ROUTE blocks the mint blocks the
planner, so the rebinding bin outranked the planner attribution even though the planner
finding was more interesting.* **Ties broken by depth, deepest-predecessor first** — the
Ladder's stop rule as a sort key.

**R3 · GROUND PROXIMITY — does it move the counter, or is it apparatus about apparatus.**
Between items of equal expiry and blocking, **the one nearer the ground wins.** This is the
correction for the failure I diagnosed: apparatus is where measurement is easy, so it wins
ties unless something explicitly stops it.

**R4 · COST TO SETTLE — cheapest first, among equals.**
Not because cheap is better, but because **settling re-runs the ranking**, and a cheap
settlement buys a fresh ordering sooner.

**THE FALSIFIER FOR THE RANKING ITSELF:** if the order it produces is the same order I would
have chosen anyway, it is a description of my judgement and not a rule. **So it must
occasionally produce an order I disagree with, and I follow it and record that I did.** A
ranking that never surprises its author is the ranking's author with extra steps.

## WHAT THESE THREE DO TOGETHER
§1 says what proceeds. §2 says what halts it. §3 says what proceeds *first*. **The absence
becomes affordable when all three are mechanical** — and the failure mode they are guarding
against is not recklessness. It is **a queue that quietly reorders itself around whatever is
easiest to measure**, which is what happened this week without anyone deciding it.
