Read top-down. STOP at the first rung that reads wrong — everything below it is
uninterpretable until fixed.
0  levels_completed — the only currency. Moved => diagnostics on a success.
1  Residual — R_tau non-zero AND LOCALIZED (the year-old binding constraint; check first).
1b Characterization — drained records carry sigma (+patches under PATCH_BOARD_FRACTION).

## THE QUESTIONS (asked every diagnostic beat)
SELF-DIAGNOSIS (the real one):
1. If the pipeline stalled at each stage in turn, WHICH stage would report it and HOW
   would I know? Any stage with no answer is a blind spot — blind spots are why three
   eras looked identical from outside.
2. Where does the pipeline currently fail SILENTLY — a plausible value instead of an
   error? Name every one.
3. Is there a readout distinguishing NOTHING ARRIVED from ARRIVED-AND-REJECTED? They
   look the same in most logs and need opposite responses.
ON THE LADDER:
4. Per rung — residual, mint, verify, adopt, drive, objective — the number THIS BEAT,
   and where is it zero? First zero from the top is the diagnosis.
5. Is the first zero a STARVED socket or a MISSING one? Starved = upstream isn't
   feeding it. Missing = it can't fire at all.
6. What would the books look like if that stage were WORKING? No answer = no success
   criterion = undiagnosable.
THE TRAPS:
7. Which readings are STALE — pre-fix residue, not fresh events? (The swallow
   tail-scoping caught this once; it recurs.)
8. Which numbers are GUARANTEED by construction rather than measured? (R_T=0.000 on
   key identity; rho=0.000 at a collision-forbidding grain — both read as results.)
9. Where do two subsystems exchange a field whose meaning is IMPLIED rather than
   stated? (The level-convention defect class; identity grain still unresolved.)
THE ONE THAT KEEPS THE SEAT HONEST:
10. State the finding WITHOUT NAMING A GAME. If it can't be stated that way, it's
    content and it doesn't ship.

## THE STRUCTURAL SAFEGUARD
The PROCTOR produces the diagnosis; the CODER implements ONLY what the proctor names.
Separate reports, separate turns — the G* split: the diagnosing path and the building
path never run in one process. And if the proctor's finding is "I can't tell which
stage failed" — that is the MOST VALUABLE answer available: an instrument is missing,
which is a build you can do without ever looking at a board.
