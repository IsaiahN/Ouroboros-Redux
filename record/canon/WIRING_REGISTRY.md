# WIRING REGISTRY (rung 0c, record/canon/THE_LADDER.md) — one row per organ

THE DONE STANDARD: a build is DONE when something in the live path calls it
with real inputs. This file is the declaration layer; it states reality, it
does not hide it. It is CHECKED, not trusted:

* deterministic gate: `tests/gate/test_wiring_registry.py` — every LIVE row's
  SITE FINGERPRINT still resolves AND the symbol is referenced from a
  production module (non-import AST scan; `__init__` re-exports do NOT count —
  the vulture blind spot). Every SEVERED row asserts the INVERSE, so a silent
  reconnection goes red until this file is updated. Every class in
  `engines/egocentric/*.py` must have a row, and every MODULE reachable from
  the six production entrypoints (lazy imports included) must have a row or a
  reasoned entry in the gate's `NO_ROW_ALLOWLIST`; a new organ with no receipt
  is UNSHIPPABLE.
* empirical gate: `tools/live_coverage_diff.py` — branch coverage from a
  bounded synthetic episode diffed against the LIVE rows; a receipt whose line
  never executes is reported SEVERED-EMPIRICAL (`severed count=N` is the
  rung-0c line). A real-game operator-invoked run is the stronger mode; the
  synthetic run is the CI-safe floor.

Row format (machine-parseable; the gate parses exactly this):
`| name | symbol (module:qualname) | site | status | date | note |`
Status ∈ LIVE / SEVERED / DELETED-PENDING.

## THE SITE CELL IS A SYMBOL FINGERPRINT (2026-08-21)

    file:ENCLOSING/KIND:NAME#ORDINAL@LINE

* `ENCLOSING` — the innermost `def`/`class` QUALNAME containing the site
  (`<module>` at top level). `KIND` ∈ `CALL` / `REF` (a bare Name/Attribute:
  constants and annotations) / `DEF` (the definition itself). `ORDINAL` — the
  0-based index among same-KIND same-NAME nodes whose innermost enclosing
  scope is ENCLOSING, in (line, column) order.
* **`@LINE` IS A COURTESY AND IS NEVER ASSERTED.** A stale `@LINE` is not red.
  It exists so a reader can jump to the site, and so `demote` can restore the
  old `file:line` form exactly (the undo).
* For LIVE rows the fingerprint names the live-path call site. For SEVERED rows
  it names the ORGAN'S OWN `DEF`; where the historic wire-break line was in a
  different file it rides in the note as `[break=file:line]`, because a break
  line is a POSITION, and a position is what stopped being an anchor here.
* Tooling: `python -m tools.wiring_receipts migrate | refresh | demote`
  (dry run by default; `--write` to touch this file). `refresh` repairs
  courtesies only — never a gate failure, never CI. The gate does not write
  this file.
* Note markers the gate honors: `[helper]` (own-module reference counts),
  `[alias=NAME]` (consumed under another name), `[referenced-but-dead]`
  (deterministically referenced, semantically dead — inverse check waived
  loudly; the coverage diff owns it).
