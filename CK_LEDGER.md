# THE CORE KNOWLEDGE LEDGER — legitimacy-checked priors for the closure

Source: Isaiah's compiled citable ledger (compass_artifact_wf-8db5c04f, 2026-08-13) +
Tier 1/2 additions. This is the operational condensation; the four-year-old test is the
standing legitimacy gate for every hookup: "Would a four-year-old have this, before seeing
this game?" Yes -> wire it. No -> you are encoding the answer and the composition claim dies.

## THE LINE (Part H, binding on all builders)
ASSUMABLE (core, universal, pre-cultural): object cohesion/persistence/contact; occlusion,
containment, support, collision, solidity; object tracking (~3-4 slots — a machine may raise
the limit); perceptual (launching) causality; animacy, goal-attribution, rational-action
efficiency, contingency; self-agency (my action caused that change); subitizing (<=4) + ANS
ratio comparison + ordinality + small +/-; distance/angle/sense/length, symmetry, rotation,
translation, scaling, inside/outside, connectedness, holes; Gestalt grouping (proximity,
similarity, closure, continuation, common fate); statistical/sequence learning;
change/novelty/habituation; mental rotation.

FORBIDDEN (cultural — never assume): letters, numerals-as-symbols, verbal counting, exact
large arithmetic, arrows, colour semantics (green=go), reading order, screen/HUD conventions
(button semantics must be DISCOVERED), real-world object identities (key, flower), trained
games. [Our letters-wall watchdog and answer-firewall already enforce this spirit.]

CONTESTED (wire behind ablation flags): causal Bayes-net learning, intuitive statistics,
event segmentation, within-task symbol binding (the capacity is edge-core; the lexicon is
cultural).

## TIER 1 ADDITIONS (accepted, universal, absent from Spelke/Chollet lists)
1. STRUCTURE MAPPING / ANALOGY (Gentner): correspondence = relational alignment independent
   of surface features; systematicity favours deep connected structure. ARC is analogy by
   Chollet's own description and analogy is nowhere in his prior list — the largest gap.
   [Ours: the triangulation consumer + signature-first matching IS proto-structure-mapping;
   sigma's invariants are relational descriptors. Systematicity = ranking rule.]
2. ABSTRACT RULE / VARIABLE BINDING (Marcus 1999): 7-month-olds extract ABA vs ABB and
   generalize to novel tokens — an open variable bound to a role.
   [Ours: THE g7=0 WALL. Raw pixel-patch atoms have no variables; typed parameterized
   transforms are the fix. Measured 2026-08-13: lp85 g1..g6=194, g7=0.]
3. AFFORDANCE PERCEPTION (Gibson): objects specify what actions they permit, scaled to the
   actor. EFFECT is an affordance representation; ARC-3's interactive layer is affordance
   discovery. [Ours: harvest=0 for all 18 level-0 games — affordance banking is level/death-
   gated and must be un-gated.]
4. SAME/DIFFERENT as a first-class relation over pairs. [Cheap sigma predicate.]
5. CURIOSITY WITH A COMPLEXITY OPTIMUM (Kidd Goldilocks): attention to intermediate
   predictability. [Ours: affect seed_bias + MuteHandler probe could target the optimum,
   not max novelty. Flagged, Stage 3.]

## THE CAPACITY/CONTENT LAW (Isaiah, 2026-08-13) — what is built vs what is minted
THE TEST: "Can this be built from evidence available at the moment it is needed, out of
things already present? Yes -> LAZY (agent mints it). No — it is needed to OBTAIN that
evidence -> EAGER (builders wire it)." A capacity cannot be lazily acquired because it is
upstream of the evidence that would justify it (EFFECT: you cannot notice before/after
transforms without the capacity to represent a before/after pair). Content composes on
demand; eager content is the elaboration trap (the letters wall, measured 160:1).
CONVERGENCE: the capacity/content line IS the firewall line — builders wire sockets
(capacities, families, formats), agents mint members (transforms, affordances, rankings,
fissions, policies). A builder writing content is encoding answers.
RESOLUTION FOR AMBIGUOUS PRIORS: each ledger category contributes a FAMILY (eager: the
predictor/representational shape) and INSTANCES (lazy: per-game parameters). Gravity =
motion-extrapolation family (eager) + per-game dynamics (lazy).
RETROSPECTIVE CHECK: every measured failure was a capacity gap (no before/after percept ->
mint starvation; no parameters -> g7=0; no self/world attribution -> g4=0); every success
was content through a wired socket (504 atoms). The wheel rule governs content; it cannot
govern capacities, which precede its evidence.

## THE COMPOSABILITY LAW — how minted content composes
1. ONE CURRENCY: every capacity emits into the shared typed atom space (Gamma / fabric
   records with ttype+params+slots). A capacity with a side-channel output is a dead end —
   standing builder constraint.
2. FOUR COMPOSITION MODES cover the benchmark's composite space (arity <= 4, Halford):
   SEQUENCE (plans chain atoms), CONDITION (effect-at-X-given-state-at-Y — the arity-3
   constructor, queued CK-3), PARAMETER ABSTRACTION (dx=2, dx=3 -> dx=n; Marcus
   generalization over fillers), INVERSION (CK-2b group structure).
3. TRANSIENT THEN DURABLE: the planner composes ephemerally (plans cost nothing durable);
   the MINT makes a composition durable only when it PAID (a chain that reached d=0 and
   levelled becomes one composite atom — chunking, priced by the n=1 gate as an atom).
4. LAZY COMPOSITION: compose when a residual demands it; never enumerate eagerly.
